# HelixScylla
## CURRENTLY A WORK IN PROGRESS, DO NOT USE IN DEVELOPMENT, TEST OR PRODUCTION

ScyllaDB migration tooling for Elixir applications using Xandra.

## Features

- Generate migrations
- Run migrations
- Roll back migrations
- Roll back multiple migrations
- Reset database
- Migration status
- Version tracking
- Xandra adapter
- Application-independent configuration

## Installation

Add `helix_scylla` to your dependencies:

```elixir
def deps do
  [
    {:helix_scylla, "~> 0.1"}
  ]
end
```
